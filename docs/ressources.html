Ressources

Vous trouverez sur cette page une liste de ressources que j’utilise régulièrement et qui, je pense, méritent d’être partagées. Certaines sont abordées plus en détail dans mon blog. Les outils que j’utilise le plus souvent ou que je vous recommande le plus sont accompagnés de “✨”.

Cette liste est toujours en cours de rédaction et alimentée petit à petit. Elle est donc amenée à changer régulièrement.

Dataviz

  • Livre sur les fondamentaux de la datavisualisation (EN) : https://clauswilke.com/dataviz/

  • https://datavizcatalogue.com/ ou https://www.data-to-viz.com/

R

Packages

  • La majorité des packages du tidyverse : https://tidyverse.org/

    • ✨ ggplot2 pour créer des graphiques : https://ggplot2.tidyverse.org/

    • ✨ dplyr pour manipuler la donnée (filtrer, modifier, etc.) : https://dplyr.tidyverse.org/

    • tidyr pour nettoyer la donnée : https://tidyr.tidyverse.org/

    • purrr pour utiliser les fonctions de type .map() : https://purrr.tidyverse.org/

    • stringr pour travailler avec des chaînes de caractères : https://stringr.tidyverse.org/

    • forcats pour travailler avec les facteurs (fonctionne très bien avec ggplot2 pour réordonner les valeurs dans les graphiques) : https://forcats.tidyverse.org/

    • lubridate pour travailler avec les dates : https://lubridate.tidyverse.org/

  • ggrepel facilite l’utilisation des labels sur les figures faites avec ggplot2 : https://ggrepel.slowkow.com/

  • patchwork permet de combiner plusieurs graphiques ggplot2 : https://patchwork.data-imaginist.com/index.html

  • ✨ Utilisez sf pour travailler avec de la donnée spatiale : https://r-spatial.github.io/sf/index.html (attention à bien installer les dépendances, tout est détaillé sur le site)

  • tmap permet de créer des cartes : https://r-tmap.github.io/tmap/index.html

Tutoriels, guides

  • Un excellent guide sur comment customiser en profondeur ses graphiques avec ggplot2 : https://www.cedricscherer.com/2019/08/05/a-ggplot2-tutorial-for-beautiful-plotting-in-r/

Rédaction, Développement

Éditeurs de Code

  • Une “version” Libre et Open-Source de VSCode, VSCodium : https://github.com/VSCodium/vscodium

  • ✨ Positron est éditeur basé sur VSCode et développé par les créateurs de RStudio, excellent pour travailler en R (source, RMarkdown), en Python (source, Jupyter Notebook) et avec Quarto, qui gère les deux langages et plus encore : https://positron.posit.co/

Notebooks, Rapports

  • ✨ Je recommande vivement l’apprentissage de la syntaxe Markdown: https://www.markdownguide.org/

  • Pour générer des documents plus avancés, il existe Typst, une alternative plus complexe que Markdown et plus simple que LaTeX : https://typst.app/

  • ✨ Quarto permet de rédiger facilement des documents à partir de notebooks en R ou en Python, en intégrant la syntaxe Markdown mais aussi d’autres comme Typst. Avec Quarto, vous pouvez créer des documents HTML ou PDF, des livres, des dashboards, des blogs, etc. Ce site web et la grande majorité de ses contenus sont propulsés par Quarto ! https://quarto.org/
